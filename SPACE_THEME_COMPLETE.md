## 🔧 CUSTOMIZATION

### Change Star Count:
Edit `resources/js/particles.js`:
```javascript
let numberOfStars = (canvas.width * canvas.height) / 3000;
// Lower = fewer stars, Higher = more stars
```

### Change Particle Count:
```javascript
let numberOfParticles = Math.min(80, ...);
// Adjust 80 to desired number
```

### Change Connection Distance:
```javascript
if (distance < 150) {
// Change 150 to adjust connection range
```

### Adjust Animation Speed:
```javascript
this.speedX = Math.random() * 0.3 - 0.15;
// Increase values for faster movement
```
